# ldg-campaigns

Campaign banner and exit pop-up script for lodgify.com (Webflow).

During development this repo is served by GitHub Pages and loaded only on an unlinked WIP page through a dev loader. At go-live the script moves into Lodgify's Webflow site settings and its source moves to a Lodgify repository.

- `campaigns.js`: the script (currently a placeholder that logs to the console).
